# Getting Started with Chrome Extension Development

This project is a google chrome extension by javascript

## Available sources

Google chrome web store

## Key controls

F, f - front    clockwise

R, r - right    clockwise

U, u - up       clockwise

B, b - back     clockwise

L, l - left     clockwise

D, d - down     clockwise

Space + key - anti clockwise
